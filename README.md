# MICROSERVICES & DISTRIBUTED SYSTEMS

I design event‑driven, independently deployable services that form resilient, high‑throughput backends.

- **Communication** – REST, gRPC, GraphQL, message brokers (Kafka, RabbitMQ)
- **Patterns** – Saga, CQRS, Event Sourcing, API Gateway, Service Mesh
- **Resilience** – Circuit breakers, retries, bulkheads, distributed tracing
- **Deployment** – Container orchestration (Kubernetes), service discovery, config management
- **Testing** – Contract testing, integration pipelines, chaos engineering

> *Every microservice is built to scale independently, fail gracefully, and integrate seamlessly into a cohesive product ecosystem.*
